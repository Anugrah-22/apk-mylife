MYLIFE — ANDROID PWA

Versi ini menggunakan jalur belajar mandiri. Tidak ada kewajiban menyelesaikan materi dalam satu bulan atau satu minggu. Lima materi mingguan adalah tambahan yang tersedia untuk dipelajari kapan saja.

FITUR BELAJAR
- Status Belum dipelajari, Sedang dipelajari, dan Selesai.
- Filter daftar materi berdasarkan status.
- Materi baru tidak menghapus materi lama.
- ID materi stabil untuk menjaga progres saat kurikulum bertambah.
- Progres dan catatan disimpan secara lokal pada perangkat.
- Kurikulum dapat diperbarui melalui curriculum.json saat online; materi lokal tersedia offline setelah tersimpan.

INSTALASI ANDROID
1. Ekstrak ZIP.
2. Hosting isi folder pada alamat HTTPS (misalnya GitHub Pages). PWA tidak dapat dipasang langsung sebagai aplikasi dari ZIP.
3. Buka URL HTTPS melalui Chrome Android.
4. Menu Chrome > Tambahkan ke layar utama / Instal aplikasi.

PENTING
- Backup data dari menu cadangan sebelum mengganti versi atau membersihkan data browser.
- Progres disimpan di browser/perangkat, bukan otomatis tersinkron ke cloud.
- Pemeriksaan kurikulum otomatis memerlukan hosting HTTPS dan koneksi internet.
- Aplikasi ini bukan APK native.
